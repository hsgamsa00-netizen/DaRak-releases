# 다락 (DaRak) 내려받기

다락은 내 PC에 자료를 두는 Windows 개인 업무 앱이에요. 문서·데이터베이스·일정, 이 PC의 AI로 만드는 회의록, 파일 탐색과 검색을 한곳에서 써요.

이 저장소에는 설치 파일과 업데이트 정보만 올라와요.

## 설치
1. [Releases](../../releases/latest)에서 `DaRak-Setup-<버전>-x64.exe`를 받아 실행해요.
2. Windows가 경고를 보이면 '추가 정보' → '실행'을 눌러요(서명 인증서가 없는 개인 배포판이에요).
3. 설치는 내 계정에만 되고 관리자 권한이 필요 없어요.

## 업데이트
앱의 설정 > 일반 > 업데이트에서 새 버전을 확인하고 설치할 수 있어요(이 기능이 들어간 버전부터).

## 파일 확인
각 릴리스의 `SHA256SUMS.txt`와 설치 파일의 SHA-256 값을 비교할 수 있어요.

AI 기능에 쓰는 API 키는 설치 파일에 들어 있지 않아요. 쓰려면 설정에서 직접 넣어요.
